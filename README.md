# LesnayaFeya 🌿🧚

Небольшая настольная игра-приключение в сказочном лесу. Первый прототип сделан на HTML/CSS/JavaScript; Android-приложение открывает тот же интерфейс внутри WebView.

## Что уже есть

- Игровое поле **9 × 11 = 99 клеток**, нумерация змейкой от старта внизу слева.
- От 2 до 4 локальных игроков с цветными фишками.
- Анимированный трёхмерный кубик с броском, вращением и отскоком; результат броска — случайное число от 1 до 6.
- Пошаговое перемещение фишки по клеткам.
- Клетки ускорения, отката назад, звёздных бонусов и случайных лесных сюрпризов.
- Победа только при точном попадании на клетку 99.
- Иллюстрация главной героини `assets/fairy-leya.png`.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск HTML-прототипа

Откройте `index.html` в браузере. Для локального сервера можно выполнить из корня проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Сборка Android APK

В репозитории уже подготовлен Android-проект в `android/`. HTML-игра и картинка копируются в Android assets автоматически задачей Gradle `syncGameAssets`.

Локальная сборка (нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0, Gradle 8.10.2):

```bash
cd android
gradle --no-daemon :app:assembleDebug
```

Готовый APK:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Автоматическая сборка через GitHub Actions

Workflow `.github/workflows/android-apk.yml` запускается при каждом push в `main` и вручную через вкладку **Actions → Build Android APK → Run workflow**. После успешной сборки файл `app-debug.apk` доступен в разделе Artifacts соответствующего запуска под именем `LesnayaFeya-debug-apk`.

Это **debug APK** для установки и тестирования. Для публикации в Google Play позже потребуется отдельная release-сборка с ключом подписи и настройками распространения.
